Detailed Description

Executes configured experiment rows without Swing or rendering overhead.

One map is generated per row iteration and reused by every selected algorithm. Solver timing therefore excludes map generation, result construction, callbacks, and console output. Parallel execution uses bounded admission so queued solver work cannot retain an unbounded number of generated maps.
