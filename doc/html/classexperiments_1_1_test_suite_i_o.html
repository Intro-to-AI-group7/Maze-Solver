Detailed Description

Persistence and reporting utilities for experiment suites and results.

Suite files are versioned UTF-8 properties files with the .mstests extension. Result CSV files use RFC 4180-style quoting so suite names, identifiers, and paths remain valid when they contain commas or line breaks.
