Detailed Description

Incremental maze solver that supports DFS, BFS, Uniform Cost Search, Greedy Best-First Search, and weighted A*.

The solver keeps internal state between calls to updateSolve(), so callers can visualize or inspect each step one node at a time. Reported solve time measures the elapsed time of each search-step call, excluding timer delays and UI repaint work.

Typical usage: create a solver, set algorithm and maze, then call updateSolve() repeatedly until isFinished() returns true. Example: 



MazeSolver solver = new MazeSolver();

solver.setMaze(maze);

solver.setAlg("A*");

while (!solver.isFinished()) {

    solver.updateSolve();

}

if (solver.isSolved()) {

    List<Point> path = solver.getFinalPath();

}

Gets the cost of the parent route for the most recently visited node.

This is the current branch cost, not the sum of all explored branches. It is updated in constant time as each node is visited and remains useful for displaying progress during an incomplete search.

◆ getFinalPath()

List< Point > maze.search.MazeSolver.getFinalPath ( )
inline

Gets the final path after a successful solve.

The path is traced backward using the internal parent table, so the returned list begins at the goal and ends at the start.

Typical UI code can iterate as-is for reverse painting, or reverse the list first if start-to-goal order is preferred.

Returns
goal-to-start path points where x=col, y=row; empty if unsolved
